- `store_defense_ballista.png`
- `store_defense_arc_lens.png`
- `gold_package_small.png`, `gold_package_medium.png`, `gold_package_large.png`, `gold_package_mega.png`
- `diamond_package_small.png`, `diamond_package_medium.png`, `diamond_package_large.png`, `diamond_package_mega.png`
