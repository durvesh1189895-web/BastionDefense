# Meadow Stage maps

This directory reserves the campaign map slots for Meadow Stage Levels 1–12.

- `level-01` is reserved for the existing Meadow Pass battlefield.
- `level-02/map_2_level.jpeg` is the supplied Level 2 battlefield.
- `level-03` through `level-12` are reserved for future supplied maps.

Level 2 is 1880×836 pixels. Its gameplay route, pad centers, and Bastion
destination are kept in the game’s map registry so the supplied image remains
the visual coordinate authority.
